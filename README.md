# ClicksportBR

Plataforma web de desafios esportivos virtuais, inscrições
online e gerenciamento de premiações.

## Situação

Projeto em fase de levantamento de requisitos e planejamento.

## Abrangência

- Lançamento: Roraima.
- Expansão planejada: Fortaleza (CE) e Amazonas.

## Responsabilidade

Projeto desenvolvido para o ClicksportBR.

## Desenvolvimento local

Requisitos:
- Node.js 22 ou superior compatível com o Vite instalado.
- npm.

Instalação:

```bash
npm ci
```

Servidor de desenvolvimento:

```bash
npm run dev
```

Verificações:

```bash
npm run lint
npm run build
```

## Stack inicial

- React
- TypeScript
- Vite
- ESLint

Backend planejado:
- Supabase Auth
- PostgreSQL

A integração com o backend será realizada em etapa posterior.
