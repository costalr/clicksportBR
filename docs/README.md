## Como usar
Esta pasta reúne os documentos históricos (versão 0.1) e a **consolidação atualizada** em `00-consolidado/`. Consulte primeiro os documentos consolidados; os originais foram preservados para rastreabilidade, não são necessariamente a especificação vigente.

### Legenda de situação
- **Implementado / relatado e testado:** realizado nas sessões de desenvolvimento; não equivale a auditoria do repositório ou ambiente produtivo.
- **Decidido:** direção de produto ou UX acordada, mesmo que ainda não implementada.
- **Previsto:** requisito ou planejamento ainda não entregue.
- **Pendente de aprovação:** depende de Marcelo, da política comercial, de análise jurídica ou de verificação técnica.
