# ClicksportBR — Design System

**Versão:** 0.1
**Status:** Proposta preliminar
**Abordagem:** Mobile-first

## 1. Princípios

- Priorizar a experiência mobile.
- Utilizar uma identidade esportiva contemporânea.
- Valorizar fotografias reais.
- Manter navegação simples e intuitiva.
- Oferecer temas claro, escuro e automático.
- Garantir acessibilidade e consistência visual.

## 2. Tipografia

Fonte proposta: Inter.

| Elemento | Tamanho proposto |
|---|---|
| Display | 36–48 px |
| Título principal | 24–32 px |
| Subtítulo | 18–20 px |
| Texto padrão | 16 px |
| Texto auxiliar | 14 px |

## 3. Tokens de cores

| Token | Claro | Escuro |

## 4. Espaçamentos

Escala base: 4 px.

Valores propostos:
4, 8, 12, 16, 24, 32, 48 e 64 px.

## 5. Componentes iniciais

- Button
- Input
- SearchInput
- ChallengeCard
- Header
- Footer
- ThemeSwitcher
- Badge
- Modal
- FormField
- EmptyState
- LoadingState

## 6. Comportamento responsivo

- Mobile-first obrigatório.
- Layouts fluidos.
- Adaptação progressiva para telas maiores.
- Controles adequados para interação por toque.

## 7. Temas

Opções:
- Automático (padrão)
- Claro
- Escuro

A preferência manual deverá persistir entre visitas.

## 8. Acessibilidade

- Buscar conformidade com WCAG 2.2 AA.
- Manter foco visível.
- Permitir navegação por teclado.
- Usar rótulos acessíveis em formulários.
- Validar contraste nos dois temas.
- Adotar alvos de toque de pelo menos 44 × 44 px
  como padrão interno.

## 9. Pendências

- Aprovação da identidade visual.
- Validação da paleta.
- Definição do logotipo e suas variações.
- Seleção das fotografias.
- Testes de contraste e responsividade.
